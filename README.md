One line summing up the entrant's week: the win, the fail, the chaos.

> Built 151 entries, won zero, and one of my prizes this week was $0.00027.

Built for the [make.fun](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced) bounty "Your Week in One Line".

## How it works

`main.py` writes the line to `/output/entry.txt`. A `validate()` gate mirrors the bounty gate (1–100 characters, UTF-8, single line, not only white space, no leading or trailing space) and runs before the write.

```sh
python3 main.py
cat /output/entry.txt
```
